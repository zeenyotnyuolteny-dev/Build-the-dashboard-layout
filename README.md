# SpendWise Dashboard Shell

SpendWise is a responsive financial dashboard interface created using HTML and CSS.

## Features

- Responsive dashboard layout
- Sidebar navigation
- Dashboard header
- Six financial category cards
- CSS Grid for the main layout
- Flexbox for navigation, header, and cards
- CSS custom properties for the color theme
- Responsive design for smaller screens
- Hover and keyboard focus micro-interactions

## Categories

The dashboard includes:

- Food
- Transport
- Rent
- Entertainment
- Savings
- Utilities

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Custom Properties
- Media Queries

## Responsive Design

The dashboard changes to a single-column layout on screens smaller than 768px.

## Project Purpose

This project is the foundation of the SpendWise capstone project. It focuses on creating a clean and responsive visual dashboard without JavaScript functionality.
